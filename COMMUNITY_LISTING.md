## Title

Aural UI — Accessible Design System & Component Library

## Short tagline (summary field)

A modern, accessible Figma design system with 51 components and 9 built-in themes.

## Description

Aural UI is a modern, fully themeable design system for Figma, built end-to-end on Figma Variables. Duplicate it and you get a production-ready component library, a complete token architecture, and nine ready-to-use themes you can switch with a single click.

**What's inside**

- **51 reusable components**, built as proper variant sets — buttons, inputs, selects, comboboxes, checkboxes, switches, tables, modals, toasts, calendars, navigation, and more.
- **A two-tier token system**: 148 primitives (color ramps, spacing, radius, type) feeding 46 semantic tokens (brand, state, background, text, border).
- **9 theme modes** powered by Variables: Dark, Light, Neon, Kinetic, Prismatic, Minimal, Warm, Colorblind-friendly, and High-contrast.
- **WCAG AA** color contrast across themes.

**Organized for speed**
Pages are split by category: Foundations, Buttons & Actions, Forms & Inputs, Selection Controls, Data Display, Feedback & Status, Navigation, Overlays & Modals, and Media & Advanced.

**How to use it**

1. Duplicate the file to your drafts.
2. Open any page and use the right-panel mode switcher to preview all 9 themes instantly.
3. Drop components into your work — each is bound to the Semantic tokens, so it re-themes automatically.

Want your own brand? Edit the **Semantic** collection (or its primitives) and every component updates across all themes. Every component ships with a description for clarity.
